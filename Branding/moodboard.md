# Moodboard

CareMosaic debe sentirse como una compania suave, clara y protectora para organizar la salud diaria.

## Colores

- Morado principal: `#6b21d6`
- Morado suave de entrada: `#dab6f7`
- Mascota: `#c4a4e8`
- Morado profundo: `#3b1060`

## Acentos por feature

- Medicamentos: morado + cyan
- Citas: morado + azul
- Registro diario: morado + rosa/coral
- Insights: morado + amarillo suave
- Perfil: morado + rosa suave

## Mascota

El fantasma es el acompanante de cuidado. Aparece en momentos de guia, vacio, celebracion o recordatorio. No debe saturar pantallas clinicas o de datos.

## Regla visual

Cada feature debe mantener un toque morado de marca, sumar un acento propio y usar el fantasma para acompanamiento emocional o contextual. Los iconos medicos siguen siendo la capa funcional.
